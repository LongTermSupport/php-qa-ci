## 10:50 · finding · — — how the day got here

The owner reported "php is crashing quite a few times" with no location. Nothing in
the container showed it: no cores (the core pattern pipes to the host's
`systemd-coredump`), no fpm signals, no OOM, every pipeline log exit 0. `sudo dmesg`
reached the host kernel ring: five `php` segfaults at one instruction offset.
binutils symbolised it to `zval_undefined_cv`; the debuginfo packages pinned it to
`zend_execute.c:280`.

Time correlation put every crash inside a full-pipeline Infection phase, so the next
hours went into reproducing under Infection: a lifecycle-tracing prepend (Infection
refuses `auto_prepend_file`), strace over filtered runs, full runs, runs with a fake
DBGp listener, runs with `XDEBUG_MODE=off`, and two whole pipelines. All clean,
because they ran in the wrong consumer. Dead end recorded so nobody repeats it: the
consumer whose pipeline crashed was the other one.

## 11:20 · finding · — — the cores settle it

The owner exported the five cores from the host. Every core names the same mutant
hash; the op_array dump shows `IS_NOT_IDENTICAL` with two CONST operands; the
optimizer dump of the mutated file reproduces it without Infection; clearing bit
`0x20` of `opcache.optimization_level` removes it; a matrix of hand-written idioms
produces it too. Full evidence in `investigation.md`.

## 11:30 · decision · — — owner rulings and the shape of the plan

Rulings: skip the upstream report for now; track this in a php-qa-ci plan; nothing in
php-qa-ci may name the private consumers or their infrastructure, abstract PHP
configuration talk is fine.

The owner's candidate fixes were: disable the DFA pass at the PHP level across the
board, a php-qa-ci warning when the pass is enabled, disabling it only for Infection,
or a top-level php-qa-ci PHP config runner that also turns off JIT and similar. The
plan's Technical Decisions record the outcome: host ini as the recommendation,
a detector lane compiling real code with the default mask as the gate, a preflight
warning as the tripwire, and the Infection-only option rejected as a sole measure.
