## What was built

- `qaConfig/defect-record.neon` is the defect record. Sections `deferred` (`defect`, optional
  `class`, `found`, `deferredBy`) and `noPattern` (`defect`, `found`, `conclusion`,
  `techniques` with two or more different entries).
- `src/DefectRecord/DefectRecordReader.php` reads it. A malformed entry becomes a named
  problem (`qaConfig/defect-record.neon: deferred #1 has an unknown field "clas"; ...`) and is
  never returned as an entry. An unknown section or field is a problem too.
- `src/DefectRecord/DefectRecordCheck.php` is the lane-facing runner;
  `PhpstanIgnoreJustificationTool` runs it after the `ignoreErrors` half, always both. The
  identifier `phpqaci.phpstanIgnoreJustification` is unchanged and the registry description
  grew a clause, so the CLAUDE.md summary line changed.
- `ActiveRulesLister` lists the record in text (`Defect record (...)`) and JSON
  (`defectRecord: {path, deferred, noPattern}`), and throws on a record it cannot read, so
  `bin/rules` exits 1.
- `ActiveDefencesSummary` appends `### Deferred defects` to the generated region: one line per
  entry up to ten, a count and the path beyond, and a pointer to where a record goes when
  there is none. **Every consumer's CLAUDE.md region gains that section on the next composer
  install** (CHANGELOG says so).
- `ActiveDefencesListingDto` gained a fifth, defaulted constructor argument.

## Finding: the documented refresh command converts the specifications

`hooks-daemon remote-docs refresh --all` (the command CLAUDE/DefenceBeforeFix.md documented)
re-captured every vendored document as `fidelity: converted`, without the version markup and
clause anchors the declaration test reads. `--all --verbatim` restores verbatim captures.
The fix in this repository: the documented command now carries `--verbatim`, and
`DefenceBeforeFixDeclarationTest::testTheVendoredSpecificationsAreVerbatimCaptures` fails on a
converted copy (probe shown firing on fixture front matter). The daemon's own behaviour
is recorded as this repository's one deferred defect, `deferredBy` stating the decision is the
Owner's. The Owner may prefer to file it against the hooks daemon instead.
