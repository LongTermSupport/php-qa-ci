## 17:05 · finding · T4.1 — a line-based search is blind to this corpus

Technique 1's first pass grepped line by line and found one README instance. The
docs are hard-wrapped, so the second instance had `previous version of` on one
line and `this section` on the next. Flattening each paragraph before matching
found it. This is now a hard requirement of the detector rather than an
implementation detail, with `itFindsASelfReferenceThatStraddlesALineBreak`
pinning it — a single-line fixture would have let a line-oriented
implementation pass while being blind to most real instances.
